# Manish Bhargava — Portfolio

Personal portfolio of **Manish Bhargava**, Full Stack AI Developer & Cloud-Native Engineer.

**Code is where it starts. Shipping is where it matters.**

## Highlights
- Editorial dark / light design with a halftone portrait hero, floating glass navigation and theme toggle
- **Products** grid with filters, live links and detail panels
- Bus-route **experience** timeline that animates as you scroll
- Full **My Story** page with chapter navigation
- **Rixie** — an AI assistant that answers recruiters' questions about Manish only (5 questions per visitor, guardrails, offline fallback)
- **Let's connect** — send a message or request a call; lands in Gmail with a calendar invite

## Tech
HTML, CSS, vanilla JavaScript · Node.js serverless functions on Vercel · OpenAI / Anthropic SDKs · Nodemailer (Gmail) · Upstash Redis rate limiting

## Run locally
```bash
npm install
cp .env.example .env   # fill in your keys
npm run dev            # http://localhost:3000
```

## Deploy
See [DEPLOY.md](DEPLOY.md) — `npx vercel@latest login`, `link`, `npm run env:push`, `npm run deploy`.
